# Task 3 — 5-Star Developer Portfolio

## Files
- `index.html` — semantic portfolio structure
- `style.css` — responsive premium UI
- `script.js` — navigation, theme, scroll progress, reveal animations and form validation

## Features
- Responsive mobile/tablet/desktop design
- Sticky navigation with mobile menu
- Dark/light mode with localStorage
- Active section navigation
- Scroll progress indicator
- Reveal-on-scroll animations
- Hero, About, Skills, Projects, Education and Contact sections
- Contact form validation
- Reduced-motion accessibility support
- No external JavaScript libraries required

## Run
Open `index.html` in a browser. VS Code Live Server is recommended.

## Before submission
Replace:
- `Mango` with your preferred name
- Contact information
- Education details
- Project descriptions/links
- Skill levels if needed

The contact form is frontend-only and validates input. To actually receive messages, connect it to a backend or form service.
